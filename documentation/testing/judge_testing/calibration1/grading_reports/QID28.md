# Question ID: 28
**Question:**  
What does the ABS warning light indicate?

---

## Version V0

### V0 Answer
The ABS (Anti-lock Braking System) warning light indicates a malfunction in the ABS. If this light illuminates while driving, it means that the vehicle will still have normal braking capabilities, but the anti-lock braking system will not function. It's recommended to have the system checked by an authorized dealer.

Additionally, the ABS light will momentarily illuminate when you turn the ignition on to confirm that the lamp is functional. If it does not light up at that time or begins to flash while driving, you should also have the system checked.
