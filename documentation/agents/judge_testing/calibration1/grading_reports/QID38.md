# Question ID: 38
**Question:**  
What do the remote start LED indicator statuses mean on the remote control?

---

## Version V0

### V0 Answer
The LED indicator statuses on the remote control for the 2022 Ford Escape provide feedback on the remote start or stop commands. Here’s what each status means:

1. **Solid Green**: Remote start successful.  
2. **Solid Red**: Remote stop successful.  
3. **Blinking Red**: Request failed or status not received.  
4. **Blinking Green**: Status incomplete.
