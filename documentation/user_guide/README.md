# EscapeAssist User Guide

This directory contains the user-facing guides for the EscapeAssist project.

## Guides

1. [Preprocessing Pipeline](preprocessing.md) - how to extract and clean the Ford Escape manual into Markdown.
2. [Judge LLM Evaluation](judge_llm_evaluation.md) - how the scoring rubric works and how the judge metrics are interpreted.
3. [Streamlit UI Guide](streamlit_ui.md) - how to navigate the EscapeAssist app and use the V0, V1, V2, and dashboard pages.
4. [Evaluation Dashboard Guide](evaluation_dashboard.md) - how to inspect saved runs, compare versions, and export evaluation results.

## Recommended Reading Order

If you are new to the project, start with the preprocessing guide, then read the Streamlit UI guide, and finish with the evaluation dashboard guide.
