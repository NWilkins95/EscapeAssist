# EscapeAssist

EscapeAssist is a senior project focused on building a retrieval‑augmented assistant for the Ford Escape owner’s manual. The project explores different preprocessing strategies, evaluates their impact on retrieval quality, and prepares the data for downstream RAG pipelines.

## Project Structure

This repository uses a clean branching workflow:

### `main`
- Intentionally empty until final delivery.
- Will contain the polished, final version of the project.

### `development`
- Active work‑in‑progress branch.
- All weekly branches merge into this branch at the end of each week.

### Weekly Branches
Branches are created for each week of the project.
