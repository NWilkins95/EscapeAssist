## Preprocessing Overview

Two preprocessing variants are used:

### 1. Raw Extraction (V1)
- Extracts the entire manual as a single text/JSON output.
- No splitting or structural segmentation.
- Serves as a baseline for comparison.

### 2. Section‑Aware Extraction (V2)
- Uses Docling to detect headings and split the manual into sections.
- Produces structured Markdown and per‑section files.
- Intended for improved retrieval performance.
